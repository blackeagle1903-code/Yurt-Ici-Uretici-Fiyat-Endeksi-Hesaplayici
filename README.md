# Yurt-Ici-Uretici-Fiyat-Endeksi-Hesaplayici

Yİ-ÜFE (Yurt İçi Üretici Fiyat Endeksi), Türkiye’de üretilen ve yurt içindeki piyasalara satışa konu olan ürünlerin üretici fiyatlarında zaman içinde meydana gelen değişimleri ölçen temel bir ekonomik göstergedir.

The Domestic Producer Price Index is a key economic indicator that measures changes over time in the producer prices of goods produced in Türkiye and made available for the domestic market.
